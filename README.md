# artistrysynk

Prompt for Lovable AI: “artistrysynk.app”
Project Name:

🖌️ artistrysynk.app



Tagline:

“Create • Connect • Collaborate.”

🎯 
Mission


Build artistrysynk.app, a sleek, creative collaboration web app that connects musicians, producers, songwriters, performers, dancers, actors, directors, and other entertainment professionals in one vibrant ecosystem — to match, collaborate, and create projects together.

🌍 
Concept Overview


artistrysynk.app is a match + collaboration platform built for the entertainment and creative industry — a space where users can:

Discover other creatives by role, skills, location, or project needs.

Swipe, connect, and chat (like Tinder for collaboration).

Collaborate on music, film, performance, and creative projects.

Build a portfolio and showcase skills with media uploads (audio, video, images).

Grow a verified creative profile that leads to gigs, partnerships, and recognition.



Think: Tinder + LinkedIn + SoundCloud + IMDb — for the entire entertainment world.
👥 
Target User Categories


Each user chooses one or more roles upon signup:



Core (Priority for MVP):
🎤 Artists / Musicians (singers, rappers, instrumentalists)

🎧 Producers / Sound Engineers

✍️ Songwriters / Lyricists

💃 Performers / Dancers

🎥 Vixens / Video Models



Expanded Roles (for Phase 2+):
🎭 Actors / Actresses

🎬 Directors / Filmmakers

✍️ Screenwriters / Scriptwriters

🎨 Designers / Visual Artists (album art, graphics, stylists, makeup artists)

📸 Photographers / Videographers

🔊 Promoters / Managers / Agents

🧠 Creative Strategists / Brand Marketers

⚙️ 
Core Features
User Profiles

Role selection (multi-role)

Portfolio upload (audio, video, image, document)

“About Me” bio, skill tags, and social links

Optional verification badge for professionals

Matching System

Swipe interface to match creatives by role and goal

“Looking for” filter (e.g., artist looking for producer, director looking for actor)

Smart algorithm that prioritizes creative synergy (genre, location, style, etc.)

Messaging / Chat

Real-time chat for matches

Option to send project links, demos, or references

In-chat “Collaborate” button to start a project room

Project Collaboration Rooms

Shared space for matched users to manage creative tasks

Upload files, share notes, and update project status

Optional integration for Google Drive / Dropbox

Feed / Discover Page

Scrollable feed of featured creatives, trending collaborations, and open projects

Option to “Apply” or “Join” existing projects

Studio Mode / Workspace

Private collaboration tool for linked users

Optional media playback (for music/video preview)

Comment thread for creative feedback

Search & Filters

Role-based search (e.g., find all sound engineers in Lagos)

Genre, skill, or tag-based filtering

Notifications

For new matches, project updates, or messages

Admin Dashboard

Manage users, categories, flagged content, and verification requests

Monetization (Future Phase)



Subscription tiers (free vs pro creators)

Paid promotion of profiles/projects

Talent marketplace integration

🎨 
Design & UI Direction


Mood: Sleek, modern, creative energy

Palette: Black, white, deep purple, neon pink, electric blue

Style: A mix of Tinder’s simplicity + Behance’s showcase style

Tone: Premium, inclusive, artistic, and inspiring

Logo Idea: Wordmark “artistrysynk.app” in smooth, futuristic typography with a dot accent highlighting the “.app”

💡 
User Experience (UX) Flow
Welcome Screen:

Logo + tagline (“Create • Connect • Collaborate”)

Buttons: Join Now / Login

Signup / Role Selection:

Choose 1–3 roles + upload profile photo/video/audio

Discover / Swipe:

Swipe through creatives — right to connect, left to pass

Match / Chat:

When both swipe right, chat opens with a “Start Collaboration” option

Project Room:

Users manage project milestones and upload files collaboratively

Profile Page:

Displays user’s roles, works, and social proof

🚀 
Goal


Deliver a functional MVP that focuses on:

Seamless matching

Chat/collaboration

Portfolio showcase

Sleek and intuitive user flow



Then scale into a creative industry network where users can build, promote, and monetize collaborations.
